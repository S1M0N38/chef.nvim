INTRODUCTION                                                           *chef*

chef.nvim — Suggestions for your next meal

When you can't decide what to eat, let Neovim choose for you. `:Chef` picks a
random food ASCII art from a curated collection and displays it in a floating
terminal window. Simple, fun, and zero configuration.

REQUIREMENTS                                                   *chef-requirements*

- Neovim >= 0.12.2
- curl (https://curl.se/) for fetching ASCII art from the network

================================================================================
INSTALLATION                                                   *chef-installation*

Install using [lazy.nvim](https://github.com/folke/lazy.nvim):

>lua
  {
    "S1M0N38/chef.nvim",
    lazy = false,
    opts = {},
  }
<

- `"S1M0N38/chef.nvim"`: The plugin's GitHub repository.
- `lazy = false`: Always load — the plugin is tiny and there's no benefit to
  lazy-loading.
- `opts = {}`: No configuration options. Passed to |chef.setup()|.

For development, see |chef-development|.

================================================================================
COMMANDS                                                          *chef-commands*
                                                                      *:Chef*
:Chef ~
  Fetch a random food ASCII art and display it in a centered floating
  terminal window. Each call picks a different image from a collection of
  meals: burger, pizza, taco, coffee, and more.
  Press `q` or `<Esc>` to close the window.

:checkhealth chef ~
  Run health checks to verify chef.nvim setup. Validates:
  - `curl` is installed and available in `$PATH`

================================================================================
API                                                                  *chef-api*

chef.nvim exposes a minimal Lua API:

                                                                 *chef.setup()*
chef.setup({opts}) ~
  Setup function. Called automatically by plugin managers via `opts`.
  Currently a no-op — the plugin has no configuration options.

  Parameters: ~
    {opts} (`table?`) Unused. Reserved for future configuration.

                                                                *chef.serve()*
chef.serve() ~
  Fetch a random ASCII art and display it in a floating window.
  This is the function behind the |:Chef| command.

  On fetch failure, an error notification is shown with the title
  "chef.nvim".

DEVELOPMENT                                                   *chef-development*

chef.nvim includes a development workflow for plugin creation:

Testing: ~

Run tests using mini.test via lazy.minit:
>bash
  # Run all tests
  make test

  # Run a single test file
  make test-one MODULE=ascii

  # Run explicit file
  nvim -l tests/minit.lua --minitest tests/ascii_spec.lua
<

Health Checks: ~

Validate plugin setup and functionality:
>vim
  :checkhealth chef
<

Minimal Reproduction: ~

Debug issues using the included reproduction environment:
>bash
  nvim -u repro/repro.lua
<

Code Formatting: ~

>bash
  # Check formatting
  make lint

  # Auto-format all Lua files
  make format
<

Generate Help Tags: ~

After modifying `doc/chef.txt`, regenerate the tags file:
>bash
  nvim -c "helptags doc/" -c "q"
<

Release Automation: ~

Use conventional commit format for automatic versioning:
- `feat:` for new features (minor version bump)
- `fix:` for bug fixes (patch version bump)
- `BREAKING CHANGE:` for breaking changes (major version bump)

TROUBLESHOOTING                                           *chef-troubleshooting*

First, run the health check to identify issues:
>vim
  :checkhealth chef
<

No ASCII art appears: ~
- Check your internet connection
- Verify `curl` is installed: `which curl`
- Try fetching manually: `curl -L https://git.io/coffee`

Window closes immediately: ~
- Ensure no other plugin or mapping overrides `q` or `<Esc>` in normal mode
